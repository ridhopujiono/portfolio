## Overview

JustSubs is designed as a reusable Laravel package for managing subscriptions. The project aims to provide an administration dashboard alongside the core backend functionalities.

## Project Status

Development is currently underway. The intended scope includes the backend package, API endpoints, and a web-based dashboard, though full feature completion and public availability are yet to be confirmed.

## Technical Approach

- **Backend**: Built with Laravel to handle subscription logic.
- **Dashboard**: Administration interface for subscription management.

*Note: Billing integrations, prorations, and exact frontend stack are to be determined based on ongoing implementation.*
